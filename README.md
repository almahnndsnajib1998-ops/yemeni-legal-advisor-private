# yem# المستشار القانوني اليمني الذكي

## الموقع القانوني اليمني
yemenilaw.com

### وصف المشروع
مشروع أولي لإنشاء مساعد قانوني باللغة العربية،
يساعد في تنظيم القضايا والبحث في المصادر القانونية اليمنية.

### أهداف المشروع
- إدارة القضايا.
- تنظيم الوقائع القانونية.
- متابعة ملفات القضايا.
- الوصول إلى الموقع القانوني اليمني.
- إعداد مسودات للمذكرات القانونية مستقبلًا.

### التقنيات
- HTML
- CSS
- JavaScript
- Python وFastAPI مستقبلًا.
- قاعدة بيانات PostgreSQL مستقبلًا.

### حالة المشروع
نسخة أولية قيد التطوير.

### تنبيه
هذه النسخة ليست نظامًا قانونيًا مكتملًا أو محميًا.
لا تستخدمها لحفظ بيانات قضايا حقيقية أو سرية.
يجب التحقق من النصوص القانونية بالرجوع إلى المصادر الأصلية.eni-legal-advisor-private
